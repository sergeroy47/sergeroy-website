# Dossier audio — « Écouter ce texte »

Chaque page de texte affiche automatiquement un lecteur audio
si un enregistrement portant le même nom que la page existe ici.

Exemples :
- textes/ma-vie-numerique.html        → audio/ma-vie-numerique.m4a
- textes/kamouraska-1974.html         → audio/kamouraska-1974.m4a
- textes/famille-rosaire-yvonne.html  → audio/famille-rosaire-yvonne.m4a

Formats acceptés : .m4a (Dictaphone d'Apple) ou .mp3.

Pour ajouter un enregistrement :
1. Serge enregistre la lecture du texte (app Dictaphone sur iPhone ou Mac).
2. On dépose le fichier ici avec le bon nom.
3. On publie (git add + commit + push) — le bouton 🎧 apparaît tout seul.

Aucune modification des pages HTML n'est nécessaire.
